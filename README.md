# Personal Expense Tracker

## Project Overview

Personal Expense Tracker is a Python-based application designed to
help users record, manage and analyse their daily expenses.

## Features

- Add expenses
- View expenses
- Delete expenses
- Set monthly budget
- Check budget status
- Analyse expenses
- Validate user input
- Store expense data

## Technologies Used

- Python
- Python IDLE / VS Code
- File Handling

## Python Concepts Used

- Variables
- Lists
- Dictionaries
- Functions
- Conditional Statements
- Loops
- Exception Handling
- File Handling
- Modular Programming

## Project Modules

### main.py
Runs the main menu and connects all project modules.

### expense.py
Handles adding, viewing and deleting expenses.

### budget.py
Handles monthly budget and budget checking.

### analysis.py
Provides expense analysis.

### storage.py
Handles saving and loading expense data.

### validation.py
Handles input validation.

## How to Run

1. Open the project folder.
2. Open `main.py`.
3. Run the program.
4. Follow the menu displayed on the screen.

## Testing

The application was tested using different expense values,
categories, budget values and menu choices.

Invalid inputs were also tested to check validation and error handling.
